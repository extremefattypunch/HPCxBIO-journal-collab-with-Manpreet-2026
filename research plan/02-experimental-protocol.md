# Experimental Protocol & Runbook — MMseqs2-Triton

**Companion to:** `01-research-paper-plan.md`
**Audience:** the operator running experiments on the GPU cluster.
**Purpose:** turn Section 5 of the plan into an executable checklist — environment, datasets, exact commands, ablation sweeps, correctness gates, and empty results tables to fill in. **No results are recorded here yet**; every results table is a template.

> **Conventions.** `$NV` = an NVIDIA node, `$AMD` = an AMD node. Replace `${...}` placeholders with site-specific paths. Commands are illustrative and follow the invocations reported in Kallenborn et al. (2025); confirm exact flags against the installed MMseqs2 commit before a production run. Treat every "Gate:" line as a hard stop — do not proceed to the next phase until it passes.

---

## 0. Pre-flight checklist

- [ ] Reserve nodes: ≥1 NVIDIA L40S (primary), plus H100 and A100 if available; ≥1 AMD MI300X.
- [ ] Confirm fixed GPU clocks (disable boost variability) for benchmarking: `nvidia-smi -lgc <clk>` / `rocm-smi --setperflevel high`.
- [ ] Confirm host: 2× AMD EPYC class CPU, ≥1 TB RAM, fast NVMe scratch (for the 30 M-sequence DB and streaming tests).
- [ ] Provision ≥2 TB scratch for databases and intermediate indices.
- [ ] Record exact versions in `env_manifest.txt` (template in §1.3).

## 4. Phase-by-phase experiments

### Phase 1 — Fused gapless filter on NVIDIA (H1)

**Run.** Swap in the Triton filter (e.g., `--prefilter-backend triton`) and run D2 (synthetic TCUPS) and D1 (real TCUPS).

```bash
# Synthetic TCUPS sweep (D2): for each length l in 32 64 128 256 512 1024 2048
python bench_tcups.py --backend {cuda,triton} --length $l \
  --num-refs 5000000 --gpu $NV --dtype bf16 --repeats 5 --warmup 20

# Real TCUPS (D1)
python bench_tcups.py --backend {cuda,triton} --db refDB_30M \
  --queries queries.fasta --gpu $NV --repeats 5 --warmup 20
```

**Correctness gate (bit-exact).**
```bash
python verify_scores.py --ref cuda --test triton --pairs correctness_set.tsv

# bf16 arm: REQUIRE identical ROC1 on D1 or document any deviation
```

**Gate (Phase 1):** `max_abs_diff == 0` AND Triton TCUPS ≥ 0.85× CUDA at every length.

## 7. Statistical analysis recipe

- **Throughput/latency:** median of ≥5 runs, ≥20 warmup; report min/median/max; fixed clocks.
- **Quality deltas (TM-score, Foldseek sens., stochastic ROC1):** 5 seeds {0,1,2,3,4}; **paired bootstrap 95% CI** (10,000 resamples) on per-seed deltas vs the CUDA config; **paired Wilcoxon** p-value. Report CI and p.
- **Decision rule:** "unchanged" ⇔ 95% CI of the delta includes 0.
- Script: `stats.py --metric tmscore --a triton --b cuda --seeds 0 1 2 3 4 --bootstrap 10000`.
